# CM_2026_PROJ
Desarrollaremos &lt;name>, una red social Android para reseñar y descubrir videojuegos. Los usuarios podrán registrarse, seguir a otros perfiles, calificar títulos del 0 al 5, publicar análisis y comentar opiniones. Además, permitirá personalizar el perfil con foto, filtrar juegos por subcategorías y recibir notificaciones de la comunidad.
